Entrants submit a single line, under 200 characters, of awkward small talk that one robot says to another while they ride an elevator together. A judge model reads the lines two at a time against a brief published with the bounty and picks the funnier one, weighing whether it is really a robot's elevator line, whether machine logic shows through, whether the awkwardness lands, and whether it is funny on the first read. Three private blind rounds decide the ranking, so no score or place shows while entries are open, and the top places share the reward pool.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, standard library only) writes the entry line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` locally).

## Entry

> Sorry, my lidar has locked onto your charging port for four floors now, and I have asked it to stop twice.
